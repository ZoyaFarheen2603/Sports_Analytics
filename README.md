 🏅 Sports Analytics – Olympic Games

📌 Project Overview
Analysis of Olympic Games data using SQL, Excel, and Power BI to identify trends in sports, events, athlete participation, countries, and medals.

🎯 Objectives
- Analyze Olympic Games across seasons and decades
- Study sports, events, and athlete participation
- Analyze country/region performance and medals
- Create an interactive Power BI dashboard

 🛠️ Tools Used
- MySQL
- Excel
- Power BI
- GitHub

 📊 Project Deliverables
- EDA & SQL Analysis
- Power BI Dashboard
- MECE Analysis
- Project Presentation
- Olympic Games Dataset
